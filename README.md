# AI-Based Queue Length Prediction

A Flutter application for predicting queue lengths using AI/ML algorithms.

## Features

- Input queue parameters (service counters, service time, arrival rate, time of day)
- AI-powered queue length prediction
- Real-time visualization of results
- Service utilization indicators
- Confidence scoring for predictions
- Settings for model configuration

## Getting Started

This project is a Flutter application. To get started:

### Prerequisites

- Flutter SDK (3.11.0 or higher)
- Dart SDK
- Android Studio / Xcode (for mobile development)

### Installation

1. Clone the repository
2. Navigate to the project directory
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```

## Project Structure

- `lib/main.dart` - Main application UI
- `lib/queue_prediction_service.dart` - Prediction service using queueing theory
- `android/` - Android platform files
- `ios/` - iOS platform files
- `web/` - Web platform files
